## Implemented hypothesis and explicit algorithm

`pb00703_nonconvex_shell_20261109.py` constructs/source-binds this restricted class. It reuses historic v5 exact rational patch normalization/evaluation and v6's exact affine/trim checks without changing those producers. It separately checks every undirected geometric edge has exactly two opposite face incidences, connectedness, Euler characteristic 2, exact pairwise triangle intersection including coplanar cases, and strictly positive exact oriented volume `sum(dot(a,cross(b,c)))/6`. There is **no convex halfspace intersection** test. Canonical SHA-256 binds shell/source/role/units/frame/revision/configuration and all exact v5 patch identities/trims. Recomputing and equality-checking the certificate is mandatory at classification.

Exact rational ray direction candidates `(1,k,k²)` for positive integers k are tried without epsilon. A direction touching a face edge or lying in a facet plane is skipped; if finite direction budget is exhausted, the query is `BLOCKED`, never decided heuristically. Triangle/segment intersection controls use exact rational plane and projected-segment predicates. Geometric pair checking is quadratic with exact axis-aligned bounding-box *broadphase only*; bounding boxes are never interpreted as actual solid geometry.

The verifier constructs a **source-derived** cutter from the preserved MC-020 `cutting_head` and `cutting_neck` undercut fixture, partitions exact original coordinate planes for seam-compatible exposed facets, and applies exact affine shear `x'=x+z/5` (non-axis-aligned nominal planes). The independent oracle decides strict nominal membership by inverse shear and the two original MC-020 exact cutting boxes, not by calling the nonconvex shell classifier. This intentionally tests both the original physical reentrant void `(3/4,0,3/2)` and an exact source variant no longer representable as a finite union of MC-020 axis-aligned boxes. The head/neck shape is a cutting region; any non-cutting holder requires a **separately role-bound descriptor** and physical access/holder-clearance proof remains independently required by MC-020. Neither shape source success nor classification proves access.

## Explicit termination and unsupported classes

The deterministic bounded checker declines as `BLOCKED` if source JSON exceeds 200,000 encoded bytes, faces exceed 192, rational coordinates exceed 512 numerator/denominator bits, pair checks exceed 18,336, non-triangular trims are presented or source topology lies outside connected genus-zero shell class. The generic-ray loop is capped at `8*face_count+3` candidates. These are **execution resource/subgrammar limits**, never domain exclusions or evidence that physical input is invalid. Malformed contradictory source/role/patch/edge data instead produces a typed `SEMANTIC_BLOCKER`. No global geometric tolerance or minimum feature size is selected. Potentially valid exact singular contacts, nested shells/holes, multiple bodies, genus>0, arbitrary nonplanar rational trims, NURBS and opaque STEP imports **remain OPEN**.

This work is no universal exact finite source codec. In particular, arbitrary admitted curved imported initial stock and arbitrary nonconvex form/accessible-undercut geometry still lack a universal lowering or verified exact semantic membership route. Soundness of the pairwise-facet method for every pathological degeneracy also requires a distinct independent proof review; the executable tests are deterministic-model evidence, not a peer-reviewed mathematical theorem.
