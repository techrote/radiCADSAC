## Executed-byte custody

A top-level source hash followed by an ordinary import is insufficient: Python
may execute an already loaded project module or a valid timestamp/size-matched
bytecode cache instead. Hashing JSON and later reopening its path likewise fails
to identify the bytes actually decoded. The runtime captures every manifest
entry into a bounded immutable snapshot before any project code executes.

Project modules are compiled directly from their retained, verified buffers
with `dont_inherit=True` and `optimize=0`. A finite module-local import facade
routes ordinary project imports and explicitly reviewed dynamic aliases to one
private module per exact path. Unknown project paths and aliases refuse.
Module-local `Path`, read-only `open`, `builtins` and `importlib` facades return
the same captured buffers. Nested qualified producers retain their actual proof
functions and source checks. Their later reads also use the outer snapshot,
including checks inside older report helpers.

The same exact module object is reused for a path, preserving algebraic
constructor identity. Some original algebraic dataclasses require their module
namespace during decoration. Unique private names are therefore temporarily
registered for that compatibility requirement; the original canonical modules
are not trusted or overwritten. Context exit restores/removes only those
private registrations on success and failure. Global import hooks and global
`sys.path` are unchanged. Module-local legacy path mutations operate on a private
copy.

The snapshot deliberately stays stable if a pathname changes afterward. A new
runtime rejects the changed blob, while the existing runtime continues to use
its already verified bytes. Symlink aliases at capture, unlisted reads, writes,
unknown import paths and budget exhaustion are typed nontruth. Deterministic
attestation contains relative paths, exact blobs, byte lengths, manifest digest
and observed source/read coverage, without private UUIDs or machine-specific
absolute paths. `loaded_project_modules` lists outer-runtime loads; unchanged
new producers may additionally compile verified snapshots through their own
private loaders. It is not an exhaustive nested execution trace. The full
captured manifest and read counts identify those buffers as well.

The model bootstrap itself hashes and directly compiles the same runtime buffer;
the verifier does the same for the model. Python and its standard library remain
trusted. This mechanism constrains the reviewed project graph and its evidence
custody; it is not a security sandbox for hostile Python or a native execution
permit.

## Report input and failure behavior

The public report validator preflights exact built-in JSON types, depth, nodes,
string lengths, integer size, cycles and aggregate bytes before invoking any
legacy proof. Floats, nonfinite values, custom objects and duplicate JSON keys
are rejected. Canonical serialization keeps Boolean and integer values distinct.
The callable endpoint helper and source-metadata sorter validate bounded
ASCII integer/ratio syntax and operand sizes before `Fraction` construction,
then canonicality immediately after that bounded construction. Exponent and
decimal syntax, oversized integer parts and noncanonical fractions refuse;
JSON string length alone would not prevent exponent expansion. This correction
came from independent review and has a constructor-sentinel regression.
Caller reports never select code paths, original coefficients, producer callables
or the dependency manifest.

The full report must equal a fresh replay canonically. Missing, duplicate,
extra, wrong-source, partial-interval, altered-phase, wrong-kind or incomplete
receipts refuse. A producer exception, refusal or resource limit aborts the
complete census. There is no saved-report fallback and no partial success
reported as fifty complete sources. A closed continuum retains every-point-zero
semantics, isolated count `null` and finite-list inapplicability; it is never
encoded as an empty finite root set.

The internal `replay_sources()` interface returns fresh data-only original rows,
selected raw proof views, complete receipts and snapshot attestation. A future
separately reviewed finite physical-event consumer may translate those actual
views. The present census does not normalize every event coordinate or claim a
universal event interface.
