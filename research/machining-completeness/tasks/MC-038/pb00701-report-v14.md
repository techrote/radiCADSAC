## Exact source-derived factorization

`alpha = 2*pi*h*theta_turn(s)`, with integer `h>0`, and define

`F = (lambda + mu*cos(2*alpha) + cos(4*alpha)) * (A(s)*cos(alpha) + B(s)*sin(alpha))`.

- `C_h = (lambda + mu/2) A`,
- `S_h = (lambda - mu/2) B`,
- `C_3h = ((mu + 1)/2) A`,

- `C_5h = A/2`,

The `cos(4*alpha)` coefficient is normalized to one. This removes the irrelevant common scale ambiguity between multiplier and carrier while still defining a genuine exact source family rather than trusting a factored input representation.
