## Purpose and bounded claim

This leaf restricts every member of the qualified fifty-source zero-set cohort to finitely many closed subintervals in its **original parameter**, then reconstructs its complete original physical zero set and maximal connected nonzero cells from the actual child records. The public request accepts one allowlisted source ID and zero to six increasing canonical rational interior cuts. It accepts no coefficient specification, source chart, proof object, claimed root count or replacement event list.

The proof authority is a fresh execution of the qualified selected implicit-root refiner, including all 69 selected roots at the default 12 steps and its upstream complete source proofs. The retained result must canonically equal the qualified refiner report. A saved successful report is a consistency target, not an execution substitute.

The operation introduces no new root-isolation completeness theorem. Each child is a closed subset of an already proved original-source domain. No parameter substitution, phase reset, derivative rescaling, generic owner admission, discontinuity policy, native geometry claim or gate promotion is performed. An artificial cut does not become a new physical zero or an original source knot.

## Hypotheses and falsification criteria

The conditional mathematical hypothesis is precise: a complete ordered parent zero set, coupled with correct strict cut-to-event comparisons, determines complete closed restrictions. The implementation tests whether source-bound executable evidence can carry that premise through actual child construction and recomposition without silently losing a root, germ, endpoint or nonzero component.

A single changed source/phase binding, lost uniqueness premise, unresolved strict point, missing child, wrong closed membership, invented outside germ, unsupported join, coverage gap or failed upstream proof must prevent the complete requested result. Global count agreement is insufficient. The reconstructed original event, exterior, knot and cell records must be canonically equal to the bound fresh parent records after reconstruction from child contents.

## Original-root versus rational-cut comparison

The relation convention is −1 for root before cut, 0 for exact equality and +1 for root after cut.

A rational event uses exact rational comparison. An implicit event has a strict open original bracket `(a,b)` and an inherited unique simple-root theorem. A cut `q <= a` lies strictly before the root; `q >= b` lies strictly after it. Equality to an open isolator boundary is therefore strict root inequality. These tests run before any point evaluation.

Only `a < q < b` invokes the qualified original-source point evaluator. The evaluator preserves the original B-spline amplitudes, one-sided coefficient continuity at all original knots, global affine phase and source parameter. Its outward 80-bit rational enclosure must itself exclude zero. Under the inherited continuity and unique simple-root premise, the function has the parent's left sign throughout the portion before the root and its right sign throughout the portion after it. A strict point sign therefore decides the order. No global monotonicity premise is introduced.

The rule fails if used outside its isolator. For the conditional polynomial `(t−1/3)(t−2/3)`, the first root has unique bracket `(1/4,1/2)`, but the sign at `3/4` repeats that root's left sign even though the point is to its right. Bound comparison must take precedence.

The rule also fails without genuine uniqueness. For `(t−1/4)(t−1/2)(t−3/4)`, falsely treating `(0,1)` as a unique bracket for the first root would let the negative sign at `2/3` repeat its actual left sign while lying after it. Public callers cannot insert that premise: every source record and original event is bound to the qualified exact record before numerical work. The fixed source-record digest table is checked against every source in the fresh parent baseline.

Exact-zero points, undecided signs, outward rounding that includes zero, unsupported inputs and resource exhaustion produce nontruth. This leaf does not claim equality between an implicit root and a rational cut or invent a new rational representation.

## Child representation and one-sided orders

Each child retains the original source/whole-row hashes, parameter, phase, interval, piece edges and parent-record digest. Its own interval is a restriction in that same parameter. Original knots omitted from a custom cut list may lie inside the child; the source is never replaced by its first polynomial span.

Every child event contains the complete unchanged `original_event`, its digest and the unchanged `parent_coordinate`. Separate fields describe child location, available side signs, child order and `child_locator`. An implicit locator is clipped to `(max(a,u),min(b,v))` for child `[u,v]`; strict comparison evidence justifies any clipping within the original isolator. The original locator remains intact.

For a child-interior event, original smooth or knot-sided order is retained. At a child left endpoint, only the right/inward germ is available; at a child right endpoint, only the left/inward germ is available. A smooth parent zero supplies its order to that side. A true knot supplies the appropriate original sided order. An original exterior supplies only its existing in-source germ. Outside order and sign remain null, and child endpoint records make no global smooth multiplicity claim.

Consequently, the V6 tail100 knot retains sided order 1/1 and two positive signs without becoming a smooth odd-order crossing. V8's smooth order-2 touch retains two separate positive nonzero components. The two original exterior zeros create neither outside germs nor empty cells. True knot identity remains distinct from child-relative endpoint identity.

Each finite child also carries complete original exterior and true-knot records whose coordinates lie in its closed interval. A knot on a cut belongs to both adjacent children. Their original records must agree exactly when recomposed.

## Nonzero cells and actual reconstruction

A finite child's maximal nonzero components are intersections of parent components with its closed interval. A nonzero boundary point is included; a physical zero is excluded. Boundaries use source-scoped physical event references, exact original exteriors or rational cuts. An isolating bracket endpoint never substitutes for a physical zero coordinate.

The recomposer first independently recomputes the comparison premises and validates actual child coverage, every event membership/projection, endpoint state, source-piece intersection and cell fragment. It then reconstructs from those validated **actual child records**:

1. Original event records are deduplicated by source-local event ID in physical order. A rational zero on an interior cut must occur in precisely two adjacent children, with right-endpoint then left-endpoint roles. Every other zero must occur once.
2. Actual child-held original exteriors and knots are deduplicated with exact record agreement. Both original exteriors and all true knots must be recovered.
3. Actual cell fragments are grouped by their source-local parent component. The first/last boundaries, inclusion states, strict sign, original-piece union and crossed-knot union are rebuilt.
4. Consecutive fragments join only at the same included nonzero rational cut with matching source/component identity and signs. A true knot at such a join must be continuous and nonzero. Equal signs never permit joining across a physical zero.
5. Counts are derived from the reconstructed events and cells. Only then is the whole reconstructed zero-set record compared canonically with the original parent.

The implementation never implements reconstruction by returning `source['zero_set']`. Retaining complete original event copies is not enough to excuse corrupted child germ or cell records; those projections are independently validated before deduplication.

For a closed continuum, child events, finite counts, nonzero cells and vanishing orders are inapplicable and remain null. Closed continuum children reconstruct the original interval through exact consecutive coverage. They never become empty finite zero sets.

## Failure, resource and API contract

`restrict_original_source(case_id,cuts)` is the public operation. It validates ID, exact list type, cut count, canonical syntax, integer-operand bounds, strict ordering and source-interior membership before proof execution. A literal source-interval table is checked against the qualified source records; it lets an invalid outside request refuse before an unnecessary replay. Every rational token is lexically and arithmetically bounded before constructing a `Fraction`.

The public operation executes the complete default-12 refiner and upstream proof graph, then returns the requested partition or a typed `REFUSED` record with `proof_established: false` and no successful partial child list. `expected_report()` raises typed refusal on failure of any source in the complete demonstration. Report validation preflights the candidate before any replay and compares canonical bytes with a newly computed expected report.

Internal `partition_source`, `recompose_source`, `compare_event_with_cut` and `restrict_from_context` APIs are explicitly conditional composition helpers. They check fixed source/event identity but do not themselves establish that an upstream replay just occurred. The public path supplies that prerequisite. Tests reuse one actual checked context for cheap adversarial controls; a saved result is not substituted for the successful proof run.

The new wrapper permits at most six interior cuts, 128-character canonical rational tokens with 128-bit operands, 256-bit receipt operands, 8 MiB JSON buffers, 262,144 JSON value nodes, depth 40, 8,192-character strings, exact scalar types and 4,096-character report paths without NUL. Aliased/cyclic JSON containers, duplicate keys, floating/exponent numbers, Boolean/integer aliases and noncanonical rational spellings are refused. Point arithmetic inherits all existing finite refiner limits. The saved pretty-printed report is approximately 2.81 MB; its canonical value occupies approximately 1.74 MB.

## Implications and remaining work

For OpenSimachinist, this result provides a bounded example of trimming and recombining source-bound event information while retaining original function identity, physical order and sided knot semantics. It does not create a general curve/solid kernel or prove all machining event constructions.

For MSAC, preserving original parameter and physical event identity supports reproducible future operation lineage. This leaf adds no application flow, user interface, production service or geometry export capability.

A future broader restriction interface would need independently specified source admission, exact equality for implicit roots at rational cuts when strict signs are unavailable, and any desired reparameterization or discontinuity semantics. Those are separate obligations. The present finite operator succeeds only within its explicit qualified cohort and bounded request contract; all other cases remain nontruth.
