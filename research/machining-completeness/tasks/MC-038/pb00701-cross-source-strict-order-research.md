## Elementary exact separation theorem

If independently proven source-root coordinates a and b lie **strictly** in rational open intervals (l,r) and (u,v), respectively, then:

- If r <= u, then a < r <= u < b, so **a LESS than b**.
- If v <= l, then b < v <= l < a, so **a GREATER than b**.

Touching *open* interval boundaries safely prove strict order, because the actual roots are strictly internal. The theorem requires independently validated root identity/existence and a truly shared exact numerical coordinate, but does NOT require the source functions, phase or owner names to match.

If intervals overlap, this argument proves no equality, inequality, noncoincidence or order. The checker returns typed nontruth BLOCKED. Strict overlap is never root equality evidence. Existing #299 alone handles equality/order of complete root ranks **within one identical whole source**.

## Proven finite source-bound cases and counterexample

The checker rebuilds both complete pinned original-source reports and checks all existing producer/blob/provenance/phase pins. V27 tail0 and tail100 first roots have overlapping strict brackets and in fact identical initial physical source spans. This checker **deliberately refuses** SAME/DIFFERENT for these two different whole-source records: proving equality requires a separately checked exact restriction-identity theorem and uniqueness in that restriction, not bracket overlap. This is a useful *positive* target for later bounded work, not implicit proof in this PR.
