## Component-root event semantics

For projective phase `u=2*h*theta_turn`, an `A=0` component root can be an original event only when `sin(pi*u)=0`, hence `u` is an integer. A `B=0` root can be an event only when `cos(pi*u)=0`, hence `u` is a half-integer. Because phase is nonconstant rational affine, every such candidate source is rational. v12 enumerates the finite lattice candidates inside each exact isolating neighborhood and evaluates the owner polynomial exactly; absence of a polynomial zero at every candidate is an exact non-event proof, including algebraic-irrational component roots.

At a qualified `A=0` integer-phase event, a multiple original-event root would imply `pi=-A'/(u'B)`. At a qualified `B=0` half-integer-phase event it would imply `pi=B'/(u'A)`. All right-hand quantities are exact rational values and the denominators are nonzero, contradicting the irrationality of pi. The original event is therefore simple even when the component polynomial root itself is repeated.
