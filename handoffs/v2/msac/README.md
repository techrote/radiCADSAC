# MSAC Genesis v2 handoff

Consistency revision: **2.1** (issue #60 / DR-0025). Exact imported fixture/result identities are listed in `handoffs/evidence-dependencies-v2.1.json`. The original RCS-027 package tree remains preserved as correction provenance.

This is the clean product-side handoff for Machinist Simulation Aided Creator. MSAC remains a direct simulated-machining engineering creation environment, not a conventional sketch/feature-tree CAD UI and not a machining game whose failure simulation obstructs geometry creation.

MSAC owns interaction, machine modules, canonical input production, project UX, preview/inspection and user-facing status. OpenSimachinist owns engineering material state and STEP generation behind a stable programme boundary. Both share `msac-journal/1.0`, immutable revision/body/lineage semantics and protected source/audio identity and provenance.

Preview can be immediate and approximate. Engineering authority cannot. STEP is mandatory primary output, defaulting to all committed material bodies, and the founding Layer-D state must be displayed honestly as `interoperability_unqualified`.
