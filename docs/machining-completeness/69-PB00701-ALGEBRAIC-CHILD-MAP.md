## Square-free is not irreducible

An isolating interval and square-free defining polynomial identify a real root, but the polynomial need not be minimal. For example, with alpha the positive root of `2x^2-1`, the polynomial `(2x^2-1)(x^2+1)` is square-free. Reduction modulo that degree-four polynomial incorrectly leaves `2alpha^2-1` nonzero and does not produce the field Q(alpha).

V45 therefore regenerates the square-free polynomial from the independently supplied source polynomial, factors it exactly over Q, and selects the unique irreducible factor with a root in the source isolating interval using preserved MC-032 Sturm counts. A linear factor rejects an alleged irrational root. Source multiplicity is regenerated by exact gcd/derivative chains, and every grouped A/B owner is checked by divisibility by the selected factor with its own multiplicity. No amplitude factor is removed from a physical source polynomial: factorization selects a coordinate representation only.

The field key is the primitive positive-leading minimal polynomial and the real-root index within (0,1). A deterministic dyadic isolating interval is regenerated from that key. Equivalent source polynomial scalings, extra factors and refined isolating intervals yield the same field embedding; distinct real conjugates do not. The full original lowered amplitude/phase/source material remains separately bound in the child record.

## Finite exact factorization argument

The implementation uses a quadratic discriminant fast path and finite Kronecker factorization for the general case. For each possible proper factor degree k up to floor(n/2), choose k+1 distinct integer points at which the primitive integer source polynomial f is nonzero. Gauss's lemma gives an integer factor g whenever f is reducible over Q, and every g(x_i) divides f(x_i). Exhaustively enumerate those finitely many signed divisors, interpolate, retain integer-coefficient degree-k candidates, and test division exactly. A factor must occur in this finite enumeration. Recursion strictly lowers degree; exhausting all candidates proves irreducibility.

This is a termination argument, not a performance qualification. No guessed degree limit, denominator limit, numerical factor oracle or search/refinement cap decides truth. The finite cache only avoids repeated work; eviction cannot change results. Memory/recursion/overflow refusal is propagated as non-truth.

## Exact field arithmetic and order

Elements are rational coefficient vectors of degree less than the selected minimal-polynomial degree. Addition and multiplication reduce by exact polynomial division. Equality and zero are vector equality because the modulus is now irreducible. Nonzero inverses use the extended Euclidean algorithm; inversion of zero and mixing distinct real embeddings are rejected.

The sign of a nonzero element is determined by exact rational Horner enclosures over the selected root interval, refined by MC-032 Sturm bisection until zero is excluded. No midpoint value is treated as the answer. The minimal-factor remainder proves the element nonzero first; continuity and shrinking isolation guarantee finite separation. Exact zero exits before refinement. This uses rational bounds as proofs, not floating-point approximations or numerical trigonometry.

## Affine restriction, reconstruction and phase

For parent-local t in [0,1], the maps are `t=alpha*u` and `t=alpha+(1-alpha)*u`, with u in [0,1]. Both widths are strictly positive by exact real-root order. The maps have endpoints 0, alpha and 1, so they meet exactly and cover the parent without gaps, overlaps or zero-width children.

Every C_h(t), S_h(t), including harmonic-zero and all non-anchor channels, is composed with both maps in Q(alpha)[u]. Each restricted polynomial is composed back with the exact inverse map and compared coefficientwise with its parent polynomial. Tests independently check closed-form quadratic coefficients and the amplitude chain rule, not only roundtrips.

For a global parent source interval [L,R], the source map is `s=L+(R-L)t`. The original rational-affine phase `offset+rate*s` is restricted symbolically with exactly the same map. Source identity, parent interval, all lowered source coefficients and original phase law enter the canonical source binding. Scaling amplitudes or changing source identity cannot be hidden merely because orientation roots stay the same.

When the original phase rate is nonzero, the internal turn is an algebraic irrational; its trigonometric equality/sign/multiplicity is explicitly NOT_ESTABLISHED here. A zero-rate phase remains rational and is deferred to existing authority, not given a new v45 event verdict. Orientation multiplicity is never relabelled as physical event multiplicity. No child is sent to a rational-only classifier.
