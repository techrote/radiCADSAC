# MC-032 — Certified classification and critical-topology event engine

MC-032 supplies the bounded event/classification layer selected by MC-026. It is an implementation boundary, not an MC-B gate decision.

## Authority split

`MC032-A` is the adaptive interval classifier boundary. It may classify a predicate only when exact/certified evidence excludes the boundary over the full source-parameter interval. Any exact-zero or critical-event interval is routed to `MC032-B`.

`MC032-B` supplies two routes. The algebraic route uses exact rational polynomial evaluation, exact derivative multiplicity, and square-free Sturm root exclusion. The analytic route consumes pre-existing validated evidence only: a separated interval that strictly excludes zero or a unique transversal root with a certified positive derivative lower bound. Binary float, epsilon, refinement depth, timeout, or budget cannot manufacture an event decision.

The still-general tangential/multiple/singular transcendental case remains `TRANSCENDENTAL_EVENT_BLOCKER (PB-007-01)`. Algebraic multiple and singular controls being exactly decidable does not imply the corresponding universal transcendental theorem.

`MC032-C` certifies bounded topology-event facts only when the event is independently certified and connectivity evidence is independently present in the common workpiece frame. Touching has zero positive volume and is not a material/body transition. Kernel/topology identifiers are never durable body or lineage authority. The durable transition/state-machine step remains MC-033.

## Certificate binding and termination

MC-032 event certificates bind the MC-002 input identity, MC-003/canonical identity, qualified sweep identity, MC-049 challenge identity, configuration identity, and decision. Stale or mutated bindings fail verification. The MC-049 set remains 64 public preselection-preregistered challenges; it is not secret held-out evidence.

All execution terminates in one of: `DECIDED`, `CERTIFIED`, `BLOCKED`, `UNCERTIFIED`, `RESOURCE_REFUSAL`, or `SEMANTIC_BLOCKER`. Refusal and uncertainty are terminal evidence states, never fallback truth.
