# PB-007-03 exact source-codec boundary

Status: **bounded exact source codec established; full PB-007-03 remains OPEN**.  
Corrective issue: #166.  
Parent gate: MC-038 / #100.  
Source baseline: `c762ba3a7c5ceff81e7c8ec2f5c37c21e1aa758c`.

## Decision

The programme now has an executable exact-rational semialgebraic source language for bounded stock/cutting/holder solids. It supports rational polynomial inequalities over `(x,y,z)`, finite Boolean composition, explicit finite bounds, exact units/frame/source identity, role separation, canonical structural hashing and source uncertainty kept separate from nominal exact geometry.

This does **not** close `PB-007-03`. MC-002 admits imported stock and arbitrary form/undercut cutter instances without restricting every valid representation to rational semialgebraic geometry. The canonical missing-constructor-is-gap rule therefore forbids narrowing those source families merely to match this implementation. Conversely, an opaque STEP/B-rep/NURBS/mesh import does not become exact source authority simply because a kernel accepts it.

## Exact controls

The deterministic model covers an exact box, exact unit-sphere quadric, a reentrant/nonconvex Boolean cutter, exact signed `1/1000000` sphere neighbours and a positive-volume `1/1000000`-width cube. Equality is reported conservatively as `BOUNDARY_CANDIDATE`; this codec does not pre-empt universal topology/connectivity authority.

Cutting and holder geometry retain distinct roles and durable source identities. A valid exact tool-source bundle does not itself certify physical access. Nonzero source uncertainty yields `UNCERTIFIED_SOURCE` for certifying membership rather than silently becoming zero uncertainty.

Adversarial checks reject binary floats as exact authority, missing units/frame/source identity, unbounded source descriptors, holder erasure, opaque importer/kernel success, tessellation/mesh equality, AABB/hull substitution and malformed/unreviewed solid grammar.

## Programme effect

The frozen **26-operation** denominator remains unchanged. `PB-007-01` remains OPEN. `PB-007-02` remains OPEN and its general membership equality route still depends on PB-007-01. `PB-007-03` remains OPEN. `PB-007-04`, PO-02 and PO-05 remain OPEN/propagated as recorded. MC-B and MC-1 remain `NOT_ESTABLISHED`.

The residual PB-007-03 obligation is a universal finite source representation/lowering and certificate route for every admitted imported-stock and arbitrary form/undercut instance, or a separately reviewed prospective product-domain change. The bounded codec is not such a universal theorem.

## Protected semantics

Historical source/audio/provenance, canonical-journal meaning, source uncertainty, positive-volume material, holder/access separation, durable body/lineage and conventional STEP semantics are unchanged. The source codec is not engineering-output qualification and cannot be used to promote mesh-wrapped or opaque STEP output.

No native, paid, production or expensive campaign is authorized by this result. Opaque import, malformed source, `BLOCKED`, `UNCERTIFIED_SOURCE`, timeout and resource refusal remain non-success outcomes.

The next pre-gate action is a dependency review of PB-007-04. MC-B must not be retried for acceptance while required pre-gate claims remain open.
